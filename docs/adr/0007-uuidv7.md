# ADR 0007 — UUIDv7 keys generated in the application

**Decision.** `app/core/ids.py` implements RFC 9562 UUIDv7 with a per-process monotonic counter, so ids sort by creation time (B-tree locality) and can be generated before insert (batch inserts, idempotency). They are not a security control; authorization never relies on unguessable ids.
